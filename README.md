# 지구쀼체험단 (웨딩·신혼 체험단 알리미)

여러 체험단 사이트의 새 공고를 **1시간마다 자동으로 모아서**, 내가 등록한 키워드(드레스, 웨딩촬영, 메이크업…)와 지역에 맞는 공고만 보여주는 사이트예요.
지원 현황(신청→선정→체험→리뷰), 캘린더, 내 캘린더에 넣기(.ics), 신랑에게 보내기, 오늘 챙길 일 알림, 백업까지 들어 있어요.

- 수집: GitHub Actions가 매시간 `crawler/crawl.js`를 실행해 결과를 `data` 브랜치의 `campaigns.json`에 저장해요.
- 화면: `index.html` 하나로 되어 있고, GitHub Pages로 무료 공개해요.
- 키워드·지역·찜·지원 기록은 방문자 각자의 브라우저에 저장돼요(로그인 없음). 기기를 옮길 땐 설정 → 백업 파일.

## 수집하는 사이트
리뷰노트 · 강남맛집 · 디너의여왕 · 뷰티의여왕 · 택배의여왕 · 서울오빠 · 링블 · 미블 · 놀러와체험단 · 포블로그 · 클라우드리뷰 · 모블 · 티블 · 스토리앤미디어 · 가보자체험단 · 리뷰플레이스 · 체리쿡 · 체험뷰 · 레뷰(첫 화면 공개 목록) · 오마이블로그 · 데일리뷰 · 체험단닷컴 · 체블 · 웨딩메이트 · 아싸뷰 · 후키 · 모두모여체험단 · 블로그랩 · 리얼리뷰 · 블로그주민센터 · 투잡커넥트 · 태그바이 · 오픈리뷰 · 마실(지자체 여행지원) · 키플랫 · 체허미 · 더먹자 · 요깃지 · 리뷰웨이브 · 메타체험단 · 이놀자 데뷰 · 리뷰통 · 잠자리체험단 · 어디야 · 파블로 · 스타일씨 · 똑똑리워드 · 후기업 · 체리뷰 · 블덱스 (50곳)

각 사이트의 robots.txt를 매번 확인해서 허용된 **목록 페이지만** 읽고, 상세 페이지는 열지 않아요. 제목·지역·마감일·짧은 제공 내역만 저장하고 사진은 가져오지 않아요.
사이트를 더하거나 빼려면 `crawler/sites.js`를 고치면 돼요.

## 자주 바꾸는 것
- 사이트 이름, 처음 방문자에게 보여줄 기본 키워드, 추천 키워드 → `index.html` 맨 위 `CHEHUM_CONFIG`
- 기능 켜고 끄기(나중에 무료/유료 나눌 때) → 같은 곳의 `features` (false로 바꾸면 숨겨져요)
- 수집 주기 → `.github/workflows/crawl.yml`의 `cron` (기본: 매시 7분)

## 직접 점검하기
```
npm install
npm test        # 추출 로직 샘플 점검
npm run crawl   # 실제 수집 (prev.json → out/campaigns.json)
```
